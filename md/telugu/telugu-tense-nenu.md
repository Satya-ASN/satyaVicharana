## నామవాచకం / సర్వనామము తో క్రియ మరియు కాలముల ఉదాహరణలు: 

<br>

**నేను - చదువు**

| నేను | క్రియ | | కాలం | | వాక్యం |
|-------|-------|-|--------|--------|---------------------|
నే**ను** | చదువు | > | భూత కాలం | > | నే**ను** (నిన్న పుస్తకం) చదివా**ను**
| |  | > | వర్తమాన కాలం | > | నే**ను** (ఇప్పుడు పుస్తకం) చదువుతున్నా**ను**
| |  | > | భవిష్యత్ కాలం | > | నే**ను** (రేపు పుస్తకం) చదువుతా**ను**

<br>

**నేను - ఆడు**

| నేను | క్రియ | | కాలం | | వాక్యం |
|-------|-------|-|--------|--------|---------------------|
| నే**ను** | ఆడు | > | భూత కాలం | > | నే**ను** (నిన్న బంతి ఆట) ఆడా**ను**
|  |  |   | వర్తమాన కాలం | > | నే**ను** (ఇప్పుడు బంతి ఆట) ఆడుతున్నా**ను**
|  |  |  | భవిష్యత్ కాలం | > | నే**ను** (రేపు బంతి ఆట) ఆడుతా**ను**
