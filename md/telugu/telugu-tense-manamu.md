## నామవాచకం / సర్వనామము తో క్రియ మరియు కాలముల ఉదాహరణలు: 

<br>

**మనము - చదువు**

| మనము | క్రియ | | కాలం | | వాక్యం |
|-------|-------|-|--------|--------|---------------------|
మన**ము** | చదువు | > | భూత కాలం | > | మన**ము** (నిన్న పుస్తకం) చదివా**ము**
| |  | > | వర్తమాన కాలం | > | మన**ము** (ఇప్పుడు పుస్తకం) చదువుతున్నా**ము**
| |  | > | భవిష్యత్ కాలం | > | మన**ము** (రేపు పుస్తకం) చదువుతా**ము**

<br>

**మనము - ఆడు**

| మనము | క్రియ | | కాలం | | వాక్యం |
|-------|-------|-|--------|--------|---------------------|
| మన**ము** | ఆడు | > | భూత కాలం | > | మన**ము** (నిన్న బంతి ఆట) ఆడా**ము**
|  |  |   | వర్తమాన కాలం | > | మన**ము** (ఇప్పుడు బంతి ఆట) ఆడుతున్నా**ము**
|  |  |  | భవిష్యత్ కాలం | > | మన**ము** (రేపు బంతి ఆట) ఆడుతా**ము**
