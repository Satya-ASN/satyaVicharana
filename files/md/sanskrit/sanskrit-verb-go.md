## The verb is built like this:
- धातु (root) + लकार (tense marker) + पुरुष (person ending)
## Base (धातु) - गच्छ



### For Present tense (लट्):

| Person  | Singular | Dual    | Plural   |
| ------- | -------- | ------- | -------- |
| **1st** | गच्छामि  | गच्छावः | गच्छामः  |
| **2nd** | गच्छसि   | गच्छथः  | गच्छथ    |
| **3rd** | गच्छति   | गच्छतः  | गच्छन्ति |


### For Future tense (लट्):
गच्छा → गमिष्या

| Person  | Singular  | Dual      | Plural     |
| ------- | --------- | --------- | ---------- |
| **1st** | गमिष्यामि | गमिष्यावः | गमिष्यामः  |
| **2nd** | गमिष्यसि  | गमिष्यथः  | गमिष्यथ    |
| **3rd** | गमिष्यति  | गमिष्यतः  | गमिष्यन्ति |


### For Past tense (लट्):

| Person  | Singular | Dual      | Plural  |
| ------- | -------- | --------- | ------- |
| **1st** | अगच्छम्  | अगच्छाव   | अगच्छाम |
| **2nd** | अगच्छः   | अगच्छतम्  | अगच्छत  |
| **3rd** | अगच्छत्  | अगच्छताम् | अगच्छन् |


### Tip
- अ = already done → past
- इष्य = intention → future
- Below stay same in present & future, Change in past

| Person | Endings Pattern |
| ------ | --------------- |
| 1st    | मि / वः / मः    |
| 2nd    | सि / थः / थ     |
| 3rd    | ति / तः / न्ति  |
