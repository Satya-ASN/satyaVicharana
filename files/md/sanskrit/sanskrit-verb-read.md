## The verb is built like this:
- धातु (root) + लकार (tense marker) + पुरुष (person ending)
## Base (धातु) - पठ् → becomes पठ


### For Present tense (लट्):

| Person              | Singular (एकवचनम्) | Dual (द्विवचनम्)     | Plural (बहुवचनम्)  |
| ------------------- | ------------------ | -------------------- | ------------------ |
| **1st (I / we)**    | पठामि (I read)     | पठावः (we two read)  | पठामः (we read)    |
| **2nd (you)**       | पठसि (you read)    | पठथः (you two read)  | पठथ (you all read) |
| **3rd (he/she/it)** | पठति (he reads)    | पठतः (they two read) | पठन्ति (they read) |


### For Future tense (लट्):
- इष्य (iṣya) is the Future Marker पठ → पठिष्यति
- This is the clearest tense signal

| Person              | Singular (एकवचनम्)       | Dual (द्विवचनम्)              | Plural (बहुवचनम्)           |
| ------------------- | ------------------------ | ----------------------------- | --------------------------- |
| **1st (I / we)**    | पठिष्यामि (I will read)  | पठिष्यावः (we two will read)  | पठिष्यामः (we will read)    |
| **2nd (you)**       | पठिष्यसि (you will read) | पठिष्यथः (you two will read)  | पठिष्यथ (you all will read) |
| **3rd (he/she/it)** | पठिष्यति (he will read)  | पठिष्यतः (they two will read) | पठिष्यन्ति (they will read) |


### For Past tense (लट्):
- Prefix अ- (Very Important)
- पठति → अपठत् → This अ indicates past

| Person              | Singular (एकवचनम्) | Dual (द्विवचनम्)        | Plural (बहुवचनम्)   |
| ------------------- | ------------------ | ----------------------- | ------------------- |
| **1st (I / we)**    | अपठम् (I read)     | अपठाव (we two read)     | अपठाम (we read)     |
| **2nd (you)**       | अपठः (you read)    | अपठतम् (you two read)   | अपठत (you all read) |
| **3rd (he/she/it)** | अपठत् (he read)    | अपठताम् (they two read) | अपठन् (they read)   |


### Tip
- अ = already done → past
- इष्य = intention → future
- Below stay same in present & future, Change in past

| Person | Endings Pattern |
| ------ | --------------- |
| 1st    | मि / वः / मः    |
| 2nd    | सि / थः / थ     |
| 3rd    | ति / तः / न्ति  |
